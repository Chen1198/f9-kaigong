========================================
  F9开工  ·  使用说明
========================================

【一句话】
  按一下 F9（或 Ctrl+Alt+W），你每天要用的软件和网页就自己全部开好。

  更想动手点？双击桌面上的「F9开工」图标，敲一下中间那只木鱼，一样的效果。

  想改清单？开始菜单里搜「F9开工」→ 点「F9开工 · 设置」，勾一勾就行。

  下班要关机？按一下 Ctrl+Alt+Q，
  弹出「关机 / 重启 / 睡眠」，带 60 秒倒计时，随时能反悔。


========================================
【桌面上只有一个图标：「F9开工」】
========================================
  ● 双击它 → 弹出「启动台」（一只干干净净的木鱼，白色底）
      敲一下中间那只木鱼 = 开工。
      鼠标移上去木鱼会亮一点；敲下去有回弹，还有一声"嗒"的敲木鱼声。
      木鱼下面写着今天要开几项，比如「05 ITEMS // READY」。
      不想开工了？点右上角那个 ✕，或者按 Esc —— 什么都不会发生。

  ● 想改清单 / 快捷键 / 皮肤 / 开工彩蛋？
      开始菜单里搜「F9开工」→ 点「F9开工 · 设置」
      （或者双击程序文件夹里的「设置.bat」，效果一样）
      全都在那一个窗口里改，改完点右下角的【保存并生效】。
      —— 启动台界面上刻意**只有"开工"这一个功能**，设置不摆在脸上。

  ● 收工呢？
      按 Ctrl+Alt+Q 就行（关机 / 重启 / 睡眠，带 60 秒倒计时，随时能反悔）。
      桌面上不再单独放「F9收工」图标了 —— 两个图标合并成了一个。

  ● 以前桌面上那两个图标哪儿去了？
      双击一次 install.bat 就会处理掉：它会把人重建、把旧的挪到程序目录里备份
      （文件名长这样：old-shortcut-日期时间.lnk.bak），不会直接删。

  不方便动手的时候，直接按快捷键 F9 或 Ctrl+Alt+W 也行 —— 效果一样，而且更省事。


========================================
【不会再闪那个黑框了】
========================================
  以前双击图标，屏幕上会先冒出一个黑色的小窗口（那是脚本的控制台），
  有时候它就赖在那儿不走。现在改掉了：

    · 桌面图标改成用系统自带的 wscript 静默启动，压根不产生黑框
    · 程序内部还会再兜一次底，万一还有残留也立刻隐藏

  如果还是看到了，双击一次 install.bat 刷新一下桌面图标就好了
  （旧版本的图标参数是老的，换成新的就不闪了）。

【四套皮肤，随你挑（选完当场生效）】
========================================
  1  简约白     大面积留白 + 墨黑强调，最克制、最耐看
  2  墨玉黑     深色底 + 香槟金，安静、有质感（适合晚上用）
  3  莫兰迪     低饱和灰调 + 陶土棕，温和不刺眼
  4  深海靛     干净白底 + 靛蓝，偏商务、偏正式

  想先看看长什么样？打开文件夹里的「screenshots」文件夹，里面有实拍图。
  （最全的说明还是「README.md」，那份更详细，也会跟着版本更新。）

  换法有两种，随便挑一种：

  ① 打开控制面板 →「③ 其它设置」→「皮肤」下拉框里选一个
     （选完立刻生效，不用点保存、也不用重开窗口，桌面图标也会跟着换）

  ② 或者双击文件夹里的「换皮肤.bat」
     → 列出所有皮肤，输入前面的数字，回车 → 完成


========================================
【③ 其它设置 里那几个开关是什么意思】
========================================
  ☑ 开机自动在后台待命（推荐勾上）
      勾上：每次开机后程序自动在后台待命，随时可以按快捷键
      不勾：以后开机不再自动待命（想用的时候双击图标就行）

  ☑ 开工时显示进度窗
      勾上（默认）→ 按快捷键后右下角出进度窗，条子一直流动，开完把开了哪几项列出来，几秒后自己收起
      不勾        → 完全安静：只在后台默默打开，一个窗口都不弹

  双击桌面图标
      弹出启动台（默认）/ 直接开工 —— 见上面第二节

  界面语言
      简体中文 / English，只换界面文字，不动你的清单
      （第一次安装时 install.bat 会问一句：按 1 = 英文，按 2 = 中文。
        什么都不按也行 —— 10 秒后按系统语言自动定：中文电脑就是中文，
        不会因为手慢变成英文。装完随时都能在这里改。）

  皮肤
      四套配色，选完当场生效

  打开程序文件夹 / 查看运行记录 / 卸载
      分别是打开这个文件夹、看运行日志、卸载


========================================
【④ 开工彩蛋：给自己一点开工仪式感】
========================================
  在控制面板最下面的「④ 开工彩蛋（可选）」里：

  ☑ 开工时飘一下表情包
      勾上后，开工时屏幕右上角会有一张表情包从上面滑下来、
      停一下、再淡出（不到 2 秒）。
      · 点【选图片…】可以用你自己的图（png / jpg / bmp / gif 都行）
      · 不选的话，就用当前皮肤自带的那个小图案
      · 点【用皮肤形象】可以清掉自己选的图

  说一句话
      打一句话，开工时让电脑自己念出来（中文也能念，不用装软件）
      例：开工啦，今天也要加油

  放音频
      选一段自己的音频（wav / mp3 / wma / m4a）
      录一段自己的声音、或者下载个喜欢的音效都行
      ★ 这个比上面那句话优先：选了音频，就不再念那句话了

  音量    系统语音的音量（0-100）
  试听一下  立刻演一遍：飘一次表情包 + 放一次语音，不会打开任何软件


========================================
【快捷键】
========================================
  开机之后它会在后台悄悄待命。任何时候按一下 F9 或者 Ctrl+Alt+W
  就能开工 —— 两个键都能用，爱按哪个按哪个。

  ★ 按下去 0.1 秒内（其实通常只有 30~80 毫秒），右下角就会浮出一个进度窗：
      一条进度条一直在流动，一边流动一边往前推进 ——
      开完一个软件就走一格，底下还写着"正在打开 xxx（2/3）"。
      全部开完，它会停几秒把开了哪几项列出来，然后自己收起来。
    所以只要右下角一出条子，就说明"按键收到了，正在开"。

  ★★ 进度条现在说的是真话：它会一直流到"软件真的出现在屏幕上"才收尾。
     以前是"启动命令发出去了就算开完"，而那个动作只要几十毫秒 ——
     于是条子 3 秒就跑满收起，可微信的窗口可能还要 20 多秒才出来，
     看着就像"程序在骗我"。现在条子会一边流一边写：
        正在启动 微信…（已等 12.4 秒）
     等窗口真的出来了，才写「到全部就绪用了 24.8 秒」，然后收起。
     ★ 所以：条子在右下角待多久，就是你那台机器真实的启动速度。
     要是超过 30 秒还没等到，它会照实写"有 1 项还没看到窗口"，不会一直转下去。

  ★ 为什么微信要 20 多秒？这跟本程序无关，是它自己启动慢。
    你这台是 2012 年的 i5（双核四线程）+ 8GB 内存。按下快捷键那一刻，
    WorkBuddy / 浏览器 / 夸克 / 企业微信 这些已经把内存吃到只剩不到 1GB，
    Windows 只能一边把内存往硬盘上倒、一边读 —— 微信就是在这种状态下冷启动，
    所以慢。硬盘本身是固态盘，没拖后腿。
    想真快一点，最管用的不是改这个程序，而是给内存腾地方：
      · 不需要的软件别让它开机自启（浏览器、夸克这类最占内存）
      · 开工前把不用的关掉，空出内存，微信就快很多
    想自己量一下到底慢在哪个软件：跑一次「自检.bat」，日志里会有
    「窗口出现: 微信 -> 24310 ms」这样的行，一眼看出是谁在慢。

  ★ 开机后第一次按会不会慢？不会。后台刚启动时就把这条路的代码提前
    "热"过一遍了（这段预热只发生在开机那几秒，你完全看不见），
    所以第一次按和之后每一次一样快。

  ★ 为什么以前按完半天没动静？因为老版本是"另外起一个新进程去开软件"，
    而 Windows 上启动一个 PowerShell 进程本身就要好几秒（杀毒软件要扫一遍）。
    现在改成后台自己开，按下去到第一个软件真的出来只要 0.1~0.2 秒。

  ★ 想让整体更快？控制面板 →「③ 其它设置」→「软件间隔」调小或设 0。
    那个数是"开下一个之前等多久"，开 3 个软件就有 2 个间隔，全都算进总时间里。

  觉得 F9 不好按、或者跟别的软件撞了？
  打开控制面板 →「③ 其它设置」→「快捷键」下拉框里选一个 → 保存并生效。

  下拉框里能选的有：
    F9 / Ctrl+Alt+W / F9 / Ctrl+Alt+W（两个都能用）/ F8 / F10 / F11 / F12
    / Ctrl+Alt+S / Ctrl+Alt+K / Ctrl+Shift+F9
  也可以自己往里打字。

  ★ 收工键（Ctrl+Alt+Q）在下面单独一行「收工快捷键」里改，
    可选：Ctrl+Alt+Q / Ctrl+Alt+E / Ctrl+Shift+Q / Ctrl+Alt+9 / Ctrl+Alt+F9
    （清空这一格 = 把收工功能整个关掉）

  ★ 小提示：单独一个 F9 属于"单键"，容易被别的软件抢走
    （比如 Excel 里 F9 是重算公式），而且容易误触。
    建议列表里保留一个组合键，或者干脆选「F9 / Ctrl+Alt+W」两个都留着。

  ★ 按了连按两下？程序会自动忽略第二下（1.5 秒内），
    免得同一批软件被打开两遍。

  ★ 同一个东西绝不会重复打开（三重保险）：
      ① 手抖连按 / 两个快捷键一起按 → 1.5 秒内只认第一下，开工过程中再按也忽略
      ② 软件本来就开着（比如微信已经开着了）→ 不会起第二个进程，
         而是**把它已经开着的那个窗口叫到最前面**（连最小化的都会先还原）——
         所以按下去屏幕上一定有反应，不会"按了跟没按一样"。
         进度窗里会写成「· 软件：微信（本来就在运行，已把它叫到最前面）」
      ③ 清单里同一个软件/同一个网址填了两遍 → 只开第一次，第二次自动忽略
    想让"已经开着的也照样再点一遍"，把 config.json 里的
    "skipIfRunning" 改成 false（改完不用重启，下次按快捷键就生效）。
    想让它"只跳过、别动窗口"（比如怕抢了你的输入焦点），把
    "activateIfRunning" 改成 false。

    想确认这两个开关现在是开的 —— 跑一次「自检.bat」，里面会有两行：
      「不重复打开: 开 —— 已经在运行的会跳过，清单里填重了也只开一次；
        现在开着的有: 微信、WorkBuddy（开工时直接跳过）」
      「已在运行就摆到最前面: 开（默认）—— 不再开第二个，而是把已经开着的窗口叫到最前面」
    括号里列出的就是"这次按快捷键会被跳过、不会重复打开"的东西。


========================================
【收工：下班前按一下 Ctrl+Alt+Q】
========================================
  按 Ctrl+Alt+Q，
  屏幕上会弹出一个窗口，里面三个按钮：关机 / 重启 / 睡眠。

  流程是这样的：
    · 先选等多少秒（默认 60 秒，5~600 都能改）
    · 点【关机】→ 窗口翻成一个大数字，一秒减一下，标题栏也写着"还有几秒"
    · 数到 0 才真的执行
    · 中途反悔：点【取消】、按 Esc、或者点右上角的 X，都立刻停下，什么都不会发生

  ★ 看到数字在跳就说明"还没执行"，你有一整分钟可以改主意。
  ★ 关机时不加"强制关闭"那个参数 —— 跟点开始菜单里的「关机」行为完全一样。
    正在写还没保存的文档，Windows 会照着平时那样问你要不要保存，不会硬关。
  ★ 「睡眠」那一项：如果你的电脑开着"休眠"（Win10/11 为了开机快默认就开着），
    点睡眠实际会变成休眠 —— 一样省电，下次开机还更快，不是按错了。

  不想用快捷键？
    那就把「收工快捷键」清空（设置 →「③ 其它设置」），收工功能会关掉。
    想要单独的收工入口，目前只有快捷键这一条路 —— 因为桌面图标合并成了一个，
    启动台界面上也刻意只留了「开工」。想要的话跟我说，加回来很快。


========================================
【顺手检查一下：现在按快捷键卡不卡】
========================================
  双击「自检.bat」跑一次全面检查。想单独量一下"处理一次按键要多久"，
  可以在程序目录里跑这条命令（不会打开任何软件，只报告耗时）：

      powershell -NoProfile -ExecutionPolicy Bypass -File Start-Workday.ps1 -SimTrigger

  它会把"处理这一次按键花了多少毫秒"写进日志。
  正常的后台，这个数字应该只有几十毫秒 —— 越小越说明按键不会被卡住。


========================================
【想换掉打开的东西？打开控制面板】
========================================
  里面所有东西都能点着改：

    ① 要打开的软件   —— 勾上就打开，取消勾选就不打开
                        点「添加软件」会列出你这台电脑上装好的程序，挑一个就行
                        点「修改」可以改名字或重新选路径
                        右边的「上移 / 下移」决定先开哪个后开哪个
    ② 要打开的网页   —— 把网址粘到框里，点「添加到列表」
                        名字可以留空，会自动用网址当名字
                        网址不用自己写 https://，程序会补
    ③ 其它设置       —— 快捷键、等待时间、几个开关、语言、皮肤
    ④ 开工彩蛋       —— 表情包、语音、音量

  · 点【立即开工一次】= 现在马上按清单打开一遍
  · 点【试运行检查】  = 只检查、不打开，告诉你快捷键能不能用、
                        每个软件找不找得到（找不到的会直接标出来）
  · 点【查看运行记录】= 每次开工都记了日志，出问题看这里
  · 点【卸载】        = 取消开机自启、删桌面图标、结束后台程序

  改完记得点右下角的【保存并生效】。


========================================
【出问题了？】
========================================
  1. 双击「设置.bat」，点【试运行检查】，它会用大白话告诉你：
       「快捷键可用」           = 没问题
       「被别的程序占用」        = 在「③ 其它设置」里换个快捷键再保存
       「后台程序正在运行中」    = 这是好消息，说明后台好好跑着呢
       「跳过软件(没找到)」      = 这软件的路径变了，在①里点「修改」重选
                                  （或者直接点「删除」，以后不打开它）

  2. 按快捷键没反应？
     大概率是"后台待命"那个小程序没在跑（它只会在你真正开机登录时自动启动；
     如果只是锁屏再解锁、或者被误关了，它就不会自己回来）。
     最快的修法：**双击一下桌面的「F9开工」图标** ——
     现在打开面板时会自动检查，发现没在跑就当场帮你拉起来，
     状态栏会显示「后台刚才没在运行，已经自动帮你启动了」。
     要是还不行，双击 install.bat 重装一次。

  2b. 电脑重启后快捷键不管用了？双击 install.bat 重装一次即可。

  3. 双击桌面图标什么也没发生？（极少见，通常是系统禁用了脚本）
     双击 install.bat 修复一下，再试。

  4. 改了程序文件之后，后台还是老样子？
     双击 install.bat —— 它会发现后台跑的是旧版本，自动帮你重启。

  5. 设置窗口打不开？双击文件夹里的「设置.bat」，效果一样。

  6. 双击桌面图标弹出一个小窗口，写着
       「Windows Script Host / 语句未结束 / 800A0401 / run-app.vbs」？
     双击 install.bat 重装一次就好了，它会重新生成这个文件并当场验语法。
     （这个文件是给桌面图标用的「静默启动器」，别用手改；程序目录里那份
       是安装时自动生成的，里面存的是你这台电脑的路径。）


========================================
【这些文件分别是什么】
========================================
  ★ 你平时只会用到桌面上那一个图标，下面这些基本不用管 ★

  设置.bat           ← 打开控制面板（桌面图标之外的备用入口）
  install.bat        ← 安装 / 修复（设开机待命 + 重建桌面图标 + 重启后台）
  uninstall.bat      ← 卸载（取消开机自启、删桌面图标、结束后台程序）
  自检.bat           ← 全面自检：查语法、查快捷键、查路径，不开任何东西
  check.bat          ← 精简自检，不带界面，结果写在 logs 里
  dryrun.bat         ← 试运行，只看会打开什么，不真打开
  edit-config.bat    ← 直接用记事本打开 config.json（手动改清单才用）
  换皮肤.bat         ← 换皮肤（列出所有皮肤，输数字选）
  screenshots\       ← 四套皮肤、启动台、右下角进度窗、收工窗口的实拍图
  hub.ico            ← 桌面那个「F9开工」图标的图案（木鱼），别删
  app.ico / setup.ico← 兜底的图标图案，别删
  run-hub.vbs        ← 桌面「F9开工」图标靠它静默启动（就是它保证不闪黑框），别删也别手改
  run-app.vbs        ← 打开控制面板用的静默启动器（备用），别删也别手改
  run-quit.vbs       ← 收工窗口用的静默启动器（命令行那条路用），别删也别手改
  quit.ico / skin_*_quit.ico ← 收工窗口的图标，别删
  skin.json          ← 皮肤配置（四套配色 + 用哪个图案），换皮肤时自动改
  art\               ← 皮肤的小图案（圆环 / 月牙 / 拱门 / 波纹）+ 启动台的图（muyu_*）
  skin_*_app.ico / skin_*_setup.ico ← 每套皮肤配套的图标，别删
  Settings-GUI.ps1   ← 控制面板的程序本体，不用管
